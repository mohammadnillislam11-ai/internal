# internal

NINMODS Client — Android Standalone Native Client (arm64-v8a)

## Features
- Direct SurfaceFlinger Native Overlay (No floating window permission needed)
- Purple Glassmorphic UI (Translucent Acrylic Theme)
- Instant Startup (No login screens or key verifications)
- ShadowHook Native Memory Engine
- Standalone Root Executable (`client.sh`)

## Build
Automated build with Android NDK via GitHub Actions.
Download the compiled `client.sh` artifact from the **Actions** tab.
