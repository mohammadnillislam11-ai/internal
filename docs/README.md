# NINMODS — Documentation Index & Developer Guide (`docs/README.md`)

> **স্বাগতম:** NINMODS রিপোজিটরির সেন্ট্রাল ডকুমেন্টেশন ইনডেক্সে আপনাকে স্বাগতম। এই ডিরেক্টরিতে ক্লায়েন্টের কোডিং স্ট্যান্ডার্ড, সিস্টেম আর্কিটেকচার, রাউটিং পাথ এবং ক্লাউড বিল্ড সম্পর্কিত সমস্ত গাইডলাইন সংরক্ষিত রয়েছে। যেকোনো কোড পরিবর্তন বা পর্যালোচনার পূর্বে ডেভেলপার ও AI এজেন্টদের এই ডকুমেন্টসগুলো পুঙ্খানুপুঙ্খভাবে অনুসরণ করা বাধ্যতামূলক।

## ২. ক্লাউড-ফার্স্ট বিল্ড পদ্ধতি (Cloud-First Build via GitHub Actions)

রুল ৭ অনুযায়ী, লোকাল মেশিনে কোনো NDK বা কম্পাইলার চালানো যাবে না। সমস্ত বাইনারি ক্লাউডে সংকলিত হয়:

1. **গিট পুশ:** কোড পরিবর্তনের পর ব্যবহারকারী মুখে স্পষ্টভাবে "পুশ করো" বললে পরিবর্তনগুলো `main` ব্রাঞ্চে পুশ করতে হবে।
2. **অটোমেটেড বিল্ড:** পুশ সম্পন্ন হওয়া মাত্রই `.github/workflows/build.yml` অ্যাকশন ট্রিগার হয়:
   - উবুন্টু রানারে Android NDK r25c কনফিগার করা হয়।
   - `refer/ZqwClient` ডিরেক্টরিতে `ndk-build -B V=1` এক্সিকিউট হয়।
   - আউটপুট বাইনারি `refer/ZqwClient/libs/arm64-v8a/client.sh` তৈরি ও ভেরিফাই হয়।
3. **আর্টিফ্যাক্ট সংগ্রহ:** GitHub রেপোজিটরির **Actions** ট্যাব থেকে প্রস্তুতকৃত `client.sh-arm64` আর্টিফ্যাক্ট সরাসরি ডাউনলোড করা যায়।

## ৩. রুটেড ডিভাইসে ক্লায়েন্ট রান করার নির্দেশিকা (Device Execution)

1. রিলিজ আর্টিফ্যাক্ট থেকে `client.sh` ফাইলটি ডিভাইসের যেকোনো ফোল্ডারে (যেমন `/data/local/tmp/`) কপি করুন:
   ```sh
   su
   cp /sdcard/Download/client.sh /data/local/tmp/ninmods
   chmod 777 /data/local/tmp/ninmods
   ```
2. ফ্রি ফায়ার বা ফ্রি ফায়ার ম্যাক্স ওপেন রেখে বাইনারিটি এক্সিকিউট করুন:
   ```sh
   /data/local/tmp/ninmods        # স্ট্যান্ডার্ড ফ্রি ফায়ার
   /data/local/tmp/ninmods ffmax  # ফ্রি ফায়ার ম্যাক্স
   ```
3. স্ক্রিনে "nin \| FPS" লেখা ফ্লোটিং পিল প্রদর্শিত হবে। পিলটিতে ট্যাপ করলে পার্পল গ্লাস থিমের মূল মেনু ওপেন হবে। মেনু থেকে "ESP Master Switch" অন করলেই তাৎক্ষণিকভাবে মেমরি রিডিং ও ভিজ্যুয়াল ওভারলে কাজ শুরু করবে।
